BulkPack is a business operations and ERP desktop application built to manage essential company workflows in one place. It supports user administration, inventory tracking, customer management, invoicing, and payment processing, helping businesses streamline daily operations and improve efficiency.

The application is developed using .NET 8, WPF, and SQL Server, with a modular architecture that makes it easy to expand with additional modules and business features.
